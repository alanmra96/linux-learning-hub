THE MENTAL MODEL

One tree, one root.

Unlike systems built around drive letters, Linux attaches disks, devices, and system resources to a single directory tree that begins at /, called “root.”

Linux file system landmarks

The interactive explorer requires JavaScript. This overview keeps the most useful beginner landmarks available without it.

/
The starting point for the entire file system.
/home
Personal files and settings for regular users.
/etc
System-wide configuration files.
/usr
Most installed programs, libraries, and shared data.
/var
Logs, caches, and other data that changes over time.
/tmp
Short-lived temporary files.

      KEY TAKEAWAY

      Paths tell you where you are.

      An absolute path begins at /, so /home/learner/notes.txt describes every step from the root directory to the file. You do not need to memorize the whole tree—learn the landmarks and explore as you go.
